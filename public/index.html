Welcome to the Huda Math Lab

Grab a pencil. We tackle the hardest problems every week.

Huda Math Lab is an initiative to teach Muslim students (grades 6+) how they can use very simple Math concepts to build real projects. The program is currently designed to be 2 terms, with each term being 8 weeks long and having 16 sessions. Each term will culminate in a final project where students will see how what they learn in the club can be used in real life (there will also be smaller projects spread throughout the curriculum!) The first term project will be using data analysis techniques with graphs to optimize egg drop designs, whereas the second term project will be using similar techniques to optimize a real, go cart size car for different types of races (students will not be riding it!).
